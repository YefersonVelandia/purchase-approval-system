# Purchase Approval System

Sistema de flujo de aprobaciones con firma digital concatenada.

## Arquitectura

Monorepo con:

- Backend serverless AWS.
- Frontend React.
- DynamoDB.
- AWS Lambda.
- Step Functions.

## Stack

### Backend

- Node.js
- TypeScript
- Serverless Framework
- AWS Lambda
- DynamoDB

### Frontend

- React
- TypeScript
- Micro Frontends
